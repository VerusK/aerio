name: Save findings incrementally
description: Save important discoveries and learnings to memory as they happen, not just at session end
type: feedback
---

Save important findings to memory incrementally — as soon as something non-obvious is discovered, not at the end of a session.

**Why:** There is no reliable "session end" signal. User wants important context preserved between sessions.
**How to apply:** Whenever a non-obvious fix, platform quirk, or important decision is made during work, save it to memory right away. Don't batch up findings.
